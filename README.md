# Syed Ayan Ahmed Jafri — Portfolio

A modern, interactive personal portfolio built with **React**, **Vite**, **Tailwind CSS**, and **React Three Fiber**.

🌐 **Live Website:** [Your Live Portfolio Link](https://portfolio-ayan-cfa1.vercel.app/)

---

## ✨ Features

- **3D Interactive Elements:** Powered by React Three Fiber for smooth visual depth.
- **Responsive Design:** Built with Tailwind CSS for seamless viewing across mobile, tablet, and desktop screens.
- **Project Showcase:** Highlights key projects with direct links to source code repositories.
- **Working Contact Form:** Integrated with a serverless Node.js API (`/api/contact`) and Nodemailer over SMTP, featuring spam protection (honeypot), origin validation, and rate limiting.

---

## 🛠️ Tech Stack

- **Frontend:** React, Vite, Tailwind CSS, React Three Fiber
- **Backend / Serverless:** Node.js (Vercel Serverless Functions), Nodemailer
- **Deployment:** Vercel
